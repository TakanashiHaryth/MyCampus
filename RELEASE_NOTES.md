# MyCampus 2.1.0 Release Notes

**Release date:** 24 August 2026

**Version:** `2.1.0`

## Changes

- Redesigned the Profile page with a cleaner, professional, and responsive layout.
- Added separate profile view and edit modes with clearer personal, academic, and account sections.
- Improved Profile layouts for Android phones, tablets, Windows, and Web.
- Fixed Add Friend requests that could fail with an `Unable to send` message.
- Improved handling for duplicate, pending, accepted, rejected, and blocked friendships.
- Added friendlier Firebase and Firestore error messages.
- Added a new MyCampus launcher icon for Android, Windows, and Web.
- Added responsive Profile tests for supported screen sizes.
- Added the Apache License 2.0.
- Removed generated Graphify, build, and debug files from version control.

Profile photo upload is not included yet because Firebase Storage has not been configured.
